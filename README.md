A project where I attempt to create am algorithm which is able to find optimal solutions to the next move


All algorithms used will not have been researched or found, but designed by me



AI Usage

AI will not be used to:
 - Write code, or take over roles which I otherwise must have filled

AI will be used to:
 - Help me make choices and understand why and when certain programming practices are used such as OOP and
   procedural programming (as this project is designed with learning how to code better as one of my main goals)
 - Help with debugging if absolutely necessary as I understand that this is a major thing I must do myself
   due as it creates a deeper understanding with the code I write and enhancing my problem spotting and solving
   skills
